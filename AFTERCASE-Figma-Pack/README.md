# AFTERCASE Figma import pack

This pack contains six desktop screens in two visual treatments:

- `wireframe/` — low-fidelity grayscale structure and hierarchy. It keeps essential control and section labels, but replaces descriptive content and styling with neutral placeholder blocks.
- `mockup/` — polished dark archival theme matching the AFTERCASE prototype.

Each SVG is an independent 1440 × 1000 artboard and can be imported as editable vector content in Figma. To import, extract the ZIP, then drag the SVG files into a Figma canvas (or use **File → Place image**). Keep the two folders in separate Figma pages named **Wireframes** and **Mockups** to compare the stages.

A wireframe does not always remove every word. It generally keeps labels needed to understand the controls and information hierarchy, while avoiding final colors, typography, imagery, and finished copy.

Screens: Login, Dashboard, Explore Cases, Case File, Add Case, and My Archive. The artwork is a static visual design reference; it does not contain live website interactions.
